# Archiver

A fast, private, multiplatform archive manager for iPhone, iPad, Mac, and Apple Vision Pro.

## Features

- **Blazing Fast In-Place Inspection:** Browse archive entries, examine directory trees, and preview images, audio, and documents without extracting full archives to disk.
- **Universal Format Support:**
  - **Read & Extract:** ZIP, 7Z, RAR, TAR, GZ, BZ2, XZ, ZSTD, Brotli, ISO, CAB, MSI, WIM, CHM, and more.
  - **Create & Compress:** ZIP, 7Z, TAR, GZ, BZ2, XZ, ZSTD.
- **Privacy & Security First:**
  - **Zero Telemetry:** No analytics, tracking SDKs, advertising, or remote server connections.
  - **AES-256 Encryption:** Create password-protected ZIP and 7Z archives with optional header encryption.
  - **Built-in Password Vault:** Store passwords securely in Apple's Keychain with optional private iCloud sync.
- **Deep Apple Platform Integration:**
  - Quick Look & dynamic format badge thumbnails in Finder and Files.
  - Share Sheet "Compress with Archiver" & "Open in Archiver" actions.
  - macOS Finder Sync toolbar actions and context menus.
  - AppleScript scripting dictionary support on macOS.
  - Universal purchase across iOS, iPadOS, macOS, and visionOS.
